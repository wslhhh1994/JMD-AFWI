# JMD-AFWI

**Joint Data- and Model- Driven Acoustic Full Waveform Inversion**

A hybrid framework that combines physics-based seismic Full Waveform Inversion (FWI) with deep learning to reconstruct subsurface P-wave velocity models from surface seismic recordings. Tested on the Overthrust benchmark model.

---

## Method Overview

The pipeline alternates between two stages:

1. **Physics-based FWI** — A 2D acoustic wave equation solver (6th-order finite difference, PML absorbing boundaries) performs forward modeling and adjoint-state gradient computation. Gradients are updated with the Adam optimizer using frequency-splitting to mitigate cycle-skipping.

2. **Joint Data- and Model- Driven Neural network training stage ** — A U-Net based architecture (`Seis_UnetModelDropout`) takes CMP (Common Midpoint) gathers as input and refines the velocity update, incorporating prior geological knowledge.

MPI parallelization distributes shot gathers across processes for scalable forward simulation.

|------|-------------|

## Usage

### Step 1 — Pre-compute CMP gather indices

```bash
python cmp.py
```

This generates lookup tables in `cmp_number/` (one `.txt` file per CMP location).

### Step 2 — Generate synthetic seismic data (optional)

```bash
mpiexec -n 45 python mpi_generate_data.py
```

### Step 3 — Run the inversion

```bash
mpiexec -n <num_procs> python seisunet_fwi_split_f_over.py
```

> **Note:** The script is configured for GPU `cuda:2` by default (`CUDA_VISIBLE_DEVICES = "2"` at line 23). Adjust to match your hardware before running.

Results are saved to `cmpfwi_over_adam_f_{favg}_linear_model_SNR_{SNR}_lowcut{lowcut_f}Hz/`.

## Key Parameters

Edit directly in `seisunet_fwi_split_f_over.py` (~line 300–350):

| Parameter | Default | Description |
|-----------|---------|-------------|
| `NX` / `NZ` | 450 / 175 | Velocity model grid size |
| `DX` / `DZ` / `dt` | 10 m / 10 m / 1 ms | Spatial and temporal sampling intervals |
| `NS` / `NR` | 45 / 450 | Number of sources / receivers |
| `favg` | 10 Hz | Ricker wavelet center frequency |
| `Tn` | 3000 | Number of time steps |
| `PML` | 30 | PML absorbing boundary thickness |
| `SNR` | 0 | Signal-to-noise ratio (0 = noise-free) |
| `lowcut_f` | 2 Hz | Low-frequency cutoff for bandpass filtering |
